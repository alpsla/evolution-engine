Known instrument limitation (disclosed, not hidden): in the Plaid report, the Change Dispersion card shows an observed value of exactly 1.50. That is the tool's internal ceiling, not a true measurement — identifiable because the identical value appears in unrelated repositories' reports, which real measurements essentially never do. Please disregard that one card; Plaid's other findings stand. Our QC caught this while screening every report on this page — flagging our own instrument's artifacts is part of the same discipline as naming every trigger commit.

How to read these: every "typical" value is computed from the repository's own history (median-based statistics, compared against a window of 20 prior commits) — no cross-repo standards. σ measures how far outside its own normal a repo moved, in units of its own normal variation. Deviation is not a defect: several spikes are healthy restructures, which is why each finding names the commit that triggered it. The fresh analyses cover git and dependency signals; build-duration and release-cadence comparisons exist only for the March set.
